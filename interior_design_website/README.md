# Interior Design Website

This project is a placeholder for an interior design website.

## Setup

Currently, this project contains:
- An `index.html` file for the main page.
- A `package.json` for Node.js dependencies (if any are added later).
- A `server.py` placeholder for a potential Python backend.

## Running the project

- To view the website, you can open the `index.html` file directly in your browser.
- If a Python server is implemented in `server.py`, you might run it using `python server.py` and access the site via `http://localhost:PORT` (where PORT is the configured port).
